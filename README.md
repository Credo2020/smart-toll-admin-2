# Smart Toll Admin 2

This is a Vite-based copy of the `smart-toll-admin` app.

## Setup

1. Open a terminal in `smart-toll-admin-2`
2. Run `npm install`
3. Run `npm run dev`

## Environment

The app reads Firebase config from `.env` using Vite env variables.

If you need to change the Firebase project, update the values in `.env`.
